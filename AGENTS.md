# Notes for coding agents

If the user wants Blank Slate on their phone, follow
[docs/install-on-iphone.md](docs/install-on-iphone.md).

## Layout

Blank Slate is an Expo SDK 54 / React Native app (iOS dev client, JSC), and
it also runs on the web and in Electron.

- `App.tsx`, `index.ts`: entry points.
- `src/agent/`: the agent loop, OpenRouter streaming, tools, system prompt.
- `src/dynamic/`: compiles generated TSX and resolves its imports
  (`requireShim.ts` lists the modules generated apps can use).
- `src/vfs/`, `src/project/`, `src/sandbox/`, `src/debug/`, `src/share/`:
  per-app files, app metadata, per-app storage, runtime history, `.blankslate`
  export/import.
- `src/screens/`, `src/theme/`: Blank Slate's own UI. `design/` has its
  design notes.
- `desktop/`: the Electron wrapper (has its own README).
- `scripts/ios-sim.sh`: builds the dev client and runs it on a simulator.
- `ios/` and `android/` are generated by `expo prebuild` and gitignored.
  Don't edit them by hand expecting the changes to stick.

## Running and checking

```sh
npm ci                      # re-run after every pull
npx tsc --noEmit            # typecheck; must pass
npx expo start --web        # web
scripts/ios-sim.sh          # iOS simulator (Xcode 27: don't use `expo run:ios`)
```

There's no test suite yet, so "it typechecks and runs" is the bar.

## Workflow

- Work on a branch, push it, and open a PR against `main` with
  `gh pr create`. Don't push to `main`.
- Don't run `eas build`, `eas update`, `eas init` or anything else that
  changes the maintainer's Expo project or Apple account unless the user asks.
  `app.json` (`owner`, `extra.eas.projectId`, `updates.url`,
  `ios.bundleIdentifier`, `ios.appleTeamId`) points at the maintainer's
  accounts.
- Don't commit `.claude/settings.local.json`, `.env` or signing files.
